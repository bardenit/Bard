Backup & Restore

Export Backup

Downloads a JSON file containing all your data. Choose whether to include transaction history (imported CSV rows).

Export Without Transactions Export Full Backup (with Transactions)

The export includes: bills, income, budget categories & budgets, expenditures, categorization rules, and account balance.
The full backup additionally includes all imported transaction records.

Restore from Backup

Upload a previously exported JSON backup file. This will replace all existing data — bills, income, budgets, expenditures, and rules. Transactions are only restored if the backup file includes them.

⚠ This action cannot be undone. Export a backup first if you want to preserve your current data.
